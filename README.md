# Swap&Play

Plataforma web de compraventa e intercambio directo de videojuegos de segunda mano desarrollada con Django REST Framework, PostgreSQL y React + Vite.

## Estructura del repositorio
- `backend/`: API REST en Django y entorno virtual local (`venv/`, ignorado por Git).
- `frontend/`: Aplicación web en React + Vite.
- `docs/`: Documentación técnica, diagramas y memoria del proyecto.
